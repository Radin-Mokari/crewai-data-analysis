## 5. Statistical Analysis
**Normality Tests (Shapiro-Wilk):**
All numeric columns (`A` through `T`) were tested for normality.
- **Finding:** Every single column showed a p-value of 0.000, which is less than 0.05.
- **Conclusion:** All tested numeric columns are **not normally distributed**. This implies that parametric statistical methods assuming normality may not be appropriate without transformations or alternative non-parametric tests.

**Correlation Significance (Pearson):**
The Pearson correlation test was performed for highly correlated pairs.
- **Finding:** All tested pairs (`C` - `D`, `D` - `E`, `E` - `F`, `F` - `G`, `C` - `E`) showed extremely high Pearson r values (e.g., 0.996 for C-D, 0.986 for C-E) and p-values of 0.000, which are less than 0.05.
- **Conclusion:** The strong positive correlations among these pairs are **statistically significant**, confirming that these variables move together in a highly predictable manner.

## 6. Feature Engineering (if applicable)
Based on the analysis, no explicit feature engineering steps have been performed yet. However, the identified issues (skewness, multicollinearity, class imbalance) point to potential future feature engineering strategies:
- **Skewed data:** Log or power transformations (e.g., Box-Cox) might be considered for columns `I` through `P` to reduce skewness and improve model performance.
- **Multicollinearity:** Given the very high correlations among `C`, `D`, `E`, `F`, `G`, and `H`, Principal Component Analysis (PCA) or selective feature dropping could be explored to reduce dimensionality and address multicollinearity if it negatively impacts model interpretability or stability.

## 7. Key Findings & Recommendations
**Key Findings:**
1.  **Data Quality:** The dataset was largely clean, with only 5 duplicate rows identified and removed. No missing values were found.
2.  **Dataset Structure:** The dataset consists of 1145 unique entries and 20 purely numeric columns.
3.  **High Skewness:** Many numeric columns (M, N, P, O, L, K, J, I, A, B) exhibit high skewness, indicating non-normal distributions concentrated towards one end of their range.
4.  **Strong Multicollinearity:** A cluster of columns (`C`, `D`, `E`, `F`, `G`, `H`) shows extremely high and statistically significant positive correlations (Pearson r > 0.9).
5.  **Non-Normal Distributions:** All 20 numeric columns were found to be statistically non-normally distributed as per the Shapiro-Wilk test (p < 0.05 for all).
6.  **Class Imbalance:**
    *   Columns `A` (99.65% vs 0.35%) and `B` (91.79% vs 8.21%) show severe class imbalance.
    *   Column `S` (66.20% vs 33.80%) and `T` (52.93% vs 47.07%) are considered balanced based on the 70/30 threshold.
7.  **Imbalance Handling Demonstration:** Class weights were computed for column 'A' (class 0: 143.125, class 1: 0.50175). SMOTE was successfully applied to column 'B', rebalancing it to 50% for each class.

**Recommendations:**
1.  **Address Skewness:** Apply appropriate data transformations (e.g., log, square root, Box-Cox, Yeo-Johnson) to highly skewed features (`M`, `N`, `P`, `O`, `L`, `K`, `J`, `I`) to normalize their distributions. This can improve the performance of models sensitive to feature distribution.
2.  **Manage Multicollinearity:** For modeling purposes, consider techniques to reduce multicollinearity among highly correlated features like `C` through `H`. This could involve:
    *   Feature selection (e.g., dropping some of the highly correlated features if redundant).
    *   Dimensionality reduction techniques like Principal Component Analysis (PCA) to create new, uncorrelated features.
3.  **Handle Class Imbalance for Targets A and B:**
    *   For column `A`, due to extreme imbalance, continue using **class weights** during model training or consider advanced oversampling/undersampling techniques with careful validation.
    *   For column `B`, the demonstrated **SMOTE** application effectively balanced the classes and should be incorporated into the modeling pipeline.
    *   No specific imbalance handling is immediately required for columns `S` and `T` given their relatively balanced distributions.
4.  **Choice of Statistical Tests:** Since all numeric columns are non-normally distributed, rely on non-parametric statistical tests or robust statistical models that do not assume normality for future analysis.
5.  **Further Feature Exploration:** Investigate the nature of columns `C` through `H` and their interdependencies more deeply to understand the underlying process they represent, which might inform more effective feature engineering.
