# Executive Summary

Feature engineering was successfully performed on the cleaned Mars weather dataset, `df_clean`, resulting in a new dataframe, `df_features`. This process generated additional predictive features from existing columns and transformed categorical data into a numerical format suitable for modeling. The final `df_features` dataset contains 1894 rows and 25 columns, expanding from the initial 10 columns of `df_raw` and the 9 columns of `df_clean`. Key transformations included extracting temporal components from `terrestrial_date`, creating cyclical representations of `ls` (solar longitude), and one-hot encoding categorical variables like `month` and `atmo_opacity`.

# Data Overview

The raw dataset, `df_raw`, initially comprised 1894 rows and 10 columns. After cleaning, `df_clean` maintained 1894 rows but was reduced to 9 columns due to the removal of `wind_speed`. The feature engineered dataset, `df_features`, now contains 1894 rows and 25 columns.

# Quality & Cleaning

The initial data cleaning steps were crucial before feature engineering.
*   **Missing Values**: The `wind_speed` column was dropped entirely due to 100% missing values. Missing values in `min_temp`, `max_temp`, and `pressure` were imputed with their respective medians: -76.0 for `min_temp`, -11.0 for `max_temp`, and 853.0 for `pressure`.
*   **Duplicate Rows**: No duplicate rows were found in the dataset.
*   **Data Type Corrections**: The `terrestrial_date` column was converted from string to datetime. `min_temp`, `max_temp`, and `pressure` were converted from float64 to int64 after imputation.
*   **Final Shape**: `df_raw` shape (1894, 10) was transformed to `df_clean` shape (1894, 9).

# Feature Engineering Process

Feature engineering expanded the `df_clean` dataset into `df_features` (1894 rows × 25 columns) by creating new features from existing ones and encoding categorical variables.

## Generated Features:
*   **Date-based Features**: From the `terrestrial_date` column, the following temporal components were extracted:
    *   `terrestrial_date_year`
    *   `terrestrial_date_month`
    *   `terrestrial_date_day_of_week`
    *   `terrestrial_date_day_of_year`
*   **Cyclical Features**: The `ls` (solar longitude) column, which ranges from 0 to 359, was transformed into sinusoidal and cosinusoidal components to capture its cyclical patterns:
    *   `ls_sin`
    *   `ls_cos`
*   **One-Hot Encoded Categorical Features**: The `month` and `atmo_opacity` string columns were converted into numerical representations using one-hot encoding, creating binary columns for each category:
    *   `month_Month 1`, `month_Month 2`, ..., `month_Month 12` (represented as `month_Month 10`, `month_Month 11`, `month_Month 12`, `month_Month 2`, `month_Month 3`, `month_Month 4`, `month_Month 5`, `month_Month 6`, `month_Month 7`, `month_Month 8`, `month_Month 9` in the `df_features` column list and sample).
    *   `atmo_opacity_Unknown` (representing the '--' values from the original `atmo_opacity` column).
