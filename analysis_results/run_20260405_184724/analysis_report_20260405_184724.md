# Quality & Cleaning
An environment check confirmed the `df_raw` loaded with shape (20640, 10). Initial data profiling identified 1 column with missing values: `total_bedrooms` with 207 missing values (1.00%). No duplicate rows were detected in `df_raw`.
Cleaning steps involved imputing missing values in the numeric column "total_bedrooms" with its median value, which was 435.0. After coercion to numeric, new NaNs in "total_bedrooms" were re-imputed with the median, 435.0. The "ocean_proximity" column was converted to a category type. The final `df_clean` maintains the shape of (20640, 10).
